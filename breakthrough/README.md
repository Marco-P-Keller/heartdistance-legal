# Breakthrough

Working folder. It currently holds one project.

## Quiet

An iPhone app: Instagram with Reels, Explore and suggested accounts removed, and
a daily time limit that can only be raised once a week — never in the moment you
want five more minutes.

→ **[Quiet/](Quiet/)** — the app. Xcode 16, SwiftUI, iOS 17, no dependencies.
